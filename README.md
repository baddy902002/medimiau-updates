# MediMiau 🐾

Ein freundlicher Begleiter für Medikamenten-Erinnerungen und ein persönliches Tagebuch.

## Android-App herunterladen

Die aktuelle freigegebene APK findest du unter **[Releases](https://github.com/baddy902002/medimiau-updates/releases/latest)**. Dies ist das öffentliche Download-Projekt; hier liegen keine persönlichen Gesundheitsdaten und kein privater Signierschlüssel.

## Updates

Ab Version 0.3.0 kann MediMiau direkt nach neuen GitHub-Releases suchen, geprüfte Updates laden und die vorhandene App aktualisieren. Nicht vorher deinstallieren: Eine Deinstallation würde lokale Einträge entfernen.

Unter **Einstellungen → App-Updates** kannst du automatische Prüfungen einschalten. Automatisches Herunterladen und Installieren ist optional. Android kann trotzdem eine Installationsbestätigung verlangen. Die einmalige Freigabe für MediMiau erteilst du selbst im Android-Dialog. Bei verweigerter Freigabe bleibt die App nutzbar.

Vor der Installation werden SHA-256-Prüfsumme, App-Kennung, Versionsnummer und dieselbe Signatur wie bei der installierten App geprüft. Vor einem Update erstellt MediMiau eine lokale Sicherung seiner Einträge. Versionshinweise stehen beim jeweiligen Release.

## Daten und Grenzen

Medikamente, Tagebuch und Gartenstand bleiben im privaten App-Speicher auf dem Gerät. Die Updateprüfung übermittelt keinen Medikamentenplan. GitHub erhält beim Abruf technische Verbindungsdaten wie die IP-Adresse. Die optionale Packungsbeilagen-Suche ist davon getrennt und informiert vor dem Senden von Medikamentenname und Stärke an Bing.

MediMiau ist eine frühe Testversion, kein medizinisch validiertes Produkt. Zeiten und Mengen müssen aus einem bestätigten Plan übernommen werden. Die App erstellt keinen persönlichen Behandlungsplan und prüft keine Wechselwirkungen. Foto-Texterkennung kann Fehler machen und ersetzt keine Kontrolle. Erinnerungen hängen von Android-Rechten und Geräteeinstellungen ab und müssen auf dem eigenen Smartphone getestet werden.

Eine allgemein freigegebene APK bedeutet keine medizinische Prüfung. Bitte die App zunächst mit fiktiven Einträgen ausprobieren.
